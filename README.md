# DevOps-DI-113152-1-Lab-

**Тақырыбы:** GitHub арқылы тармақтармен (branches) және Pull Request-пен жұмыс.

Бұл репозиторийде HTML, CSS және JavaScript көмегімен жасалған шағын **«Тапсырмалар тізімі»** веб-қосымшасы орналасқан.

## Функционалдық мүмкіндіктер

1. **Тапсырма қосу:** мәтінді енгізіп, «Қосу» батырмасын басу. Бос енгізу қабылданбайды.
2. **Тапсырманы орындалды деп белгілеу:** әр тапсырманың жанындағы құсбелгіні белгілеу немесе алып тастау.

## Іске қосу

1. Репозиторийдегі `index.html` файлын жүктеп алыңыз.
2. `style.css` және `app.js` файлдары сол қалтада болуы керек.
3. `index.html` файлын кез келген заманауи браузерде ашыңыз.
4. Тапсырма қосып, құсбелгінің жұмысын тексеріңіз.

Деректер браузер ашық тұрған кезде жедел жадыда сақталады; бетті жаңартқанда тізім тазаланады.

## Git жұмыс процесі

| Өзгеріс | Жеке тармақ | Pull Request |
| --- | --- | --- |
| Жаңа тапсырма қосу | `feature/add-task` | [PR #1](../../pull/1) |
| Орындалуын белгілеу | `feature/complete-task` | [PR #2](../../pull/2) |

Әр функционалдық өзгеріс жеке тармақта әзірленіп, Pull Request арқылы `main` тармағына біріктірілді.
